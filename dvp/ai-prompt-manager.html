🧠 AI Prompt Manager v1.2

⚡ Prompt Management & Insertion

📝
Create & Manage: Click "New Prompt" to add a prompt with title, category, and text. Each card has Edit and Delete buttons.
🔍
Search & Filter: Use the search bar to quickly find prompts by title or text. Category filters narrow down your list.
📋
Insert Prompt: Click the "Insert" button on any card — the prompt text is copied to your clipboard with a notification. Simulates pasting into an AI platform input field.
💾
Backup & Restore: Use Export and Import buttons to save all your prompts as a JSON file or restore them from a backup.
