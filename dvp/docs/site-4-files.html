Architecture Overview

Here is a short and clear explanation of how these files work together:

  • index.html — The layout (skeleton) of the page. It defines the interface structure (header, card grid, filter buttons) and ties all other files together[cite: 1].
  • styles.css — The styling and design. It handles the visual presentation: colors, fonts, spacing, shadows, and responsiveness across different screens[cite: 2].
  • data.js — The database. It stores the entire list of your lessons (dates, teacher names, titles, URLs, and card colors) to keep page code clean and uncluttered.
  • script.js — The logic and "brain". It dynamically builds the page: reads data from `data.js`, renders lesson cards inside the `index.html` grid, and brings teacher filters and the reset button to life.

How it runs in the browser:

When you open `index.html`, the browser first loads styles from `styles.css`, then fetches the lesson list from `data.js`, and uses `script.js` to instantly assemble and render the interactive catalog.

Вот короткое и понятное пояснение, как эти файлы работают вместе:

  • index.html — это каркас (скелет) страницы. Он задает структуру интерфейса (шапку, сетку карточек, кнопки фильтров) и связывает все остальные файлы воедино[cite: 1].
  • styles.css — это одежда и дизайн. Он отвечает за внешний вид: цвета, шрифты, отступы, тени и красивую адаптивность под разные экраны[cite: 2].
  • data.js — это база данных. В нем хранится весь список ваших уроков (даты, имена преподавателей, названия, ссылки и цвета карточек), чтобы не загромождать ими код страницы.
  • script.js — это мозг и логика. Он динамически собирает страницу: читает данные из `data.js`, строит карточки уроков в сетке `index.html`, а также оживляет фильтры по преподавателям и кнопку сброса.

Как это запускается в браузере:

Когда вы открываете `index.html`, браузер сначала подтягивает стили из `styles.css`, затем загружает список уроков из `data.js` и с помощью скрипта в `script.js` мгновенно собирает и отрисовывает готовый интерактивный каталог.
