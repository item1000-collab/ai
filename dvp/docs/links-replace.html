1. Задача

Сайт развёрнут на GitHub Pages по адресу:

https://item1000-collab.github.io/ai/engoo/

Внутри HTML-файлов все внутренние ссылки были абсолютными — например:

<a href="https://item1000-collab.github.io/ai/engoo/20260901-phantom-opera/index.html">Class material</a>

Это создаёт проблемы:

  • не работает локальный просмотр (через file://);
  • при смене домена (переезд, зеркало, локальный сервер) все ссылки ломаются;
  • не работает офлайн-копия сайта.

Цель — заменить все абсолютные ссылки вида https://item1000-collab.github.io/ai/engoo/… на относительные:

./20260901-phantom-opera/index.html      (из корня)
../index.html                             (из подпапки)

3. Установка Python

1Скачивание

Открыть python.org/downloads и нажать «Download Python install manager».

2Запуск установщика

В окне SmartScreen нажать «Установить Python» (издатель — Python Software Foundation).

3Настройка PATH

Откроется консольный установщик. На вопрос:

Add commands directory to your PATH now? [y/N]

Ввести y и нажать Enter.

Затем на вопрос:

Install CPython now? [Y/n]

Нажать Enter (согласиться с Y по умолчанию).

4Проверка

Открыть новую командную строку (Win+R → cmd) и выполнить:

python --version

Должно вывести версию, например:

Python 3.14.7
Готово. Python установлен и доступен из командной строки.

4. Создание скрипта замены

1Открыть Блокнот

Проще всего — из командной строки, находясь в папке engoo:

notepad replace_links.py

2Вставить код

import re
from pathlib import Path

# ==== НАСТРОЙКИ — поменяйте под себя ====
BASE_URL = "https://item1000-collab.github.io/ai/engoo"
# ========================================

ROOT = Path(".").resolve()
pattern = re.compile(re.escape(BASE_URL) + r"(/[^\s\"'<>)]*)?")

count = 0

# Ищем *.html, *.htm и файлы без расширения с именем "index"
candidates = set()
for mask in ("*.html", "*.htm"):
    candidates.update(ROOT.rglob(mask))
for p in ROOT.rglob("index"):
    if p.is_file():
        candidates.add(p)

for path in sorted(candidates):
    rel_dir = path.parent.relative_to(ROOT)
    depth = len(rel_dir.parts)
    prefix = "../" * depth if depth else "./"

    text = path.read_text(encoding="utf-8", errors="ignore")

    def repl(m):
        tail = m.group(1) or "/"
        return prefix + tail.lstrip("/")

    new = pattern.sub(repl, text)
    if new != text:
        path.write_text(new, encoding="utf-8")
        print("обновлён:", path)
        count += 1

print(f"\nГотово. Обработано файлов: {count}")

3Сохранить

Файл должен лежать в папке engoo и иметь расширение .py. Если Windows сохранил его как replace_links.py.txt — переименовать:

ren replace_links.py.txt replace_links.py

5. Запуск и результат

1Бэкап

Скопировать папку engoo в engoo_backup на случай ошибок.

2Запуск

Из командной строки, находясь в engoo:

python replace_links.py

3Результат

Скрипт выводит список обновлённых файлов и итог:

обновлён: C:\...\engoo\index
обновлён: C:\...\engoo\20260901-phantom-opera\index
…
Готово. Обработано файлов: 112
Обработано 112 файлов. Все абсолютные ссылки внутри engoo заменены на относительные.

6. Проверка результата

Поиск остатков

findstr /s /i /c:"item1000-collab.github.io" *.html index

Если найдено — значит есть ссылки, которые скрипт не обработал. Возможные причины:

  • Ссылки на другой путь — например /ai/trips/… вместо /ai/engoo/…. Скрипт настроен только на engoo.
  • Ссылки в комментариях <!-- … --> — не влияют на работу, но встречаются в тексте.

Локальная проверка

Запустить простой веб-сервер:

python -m http.server 8000

Открыть http://localhost:8000/ и походить по ссылкам.

Внимание: file:// может некорректно работать с относительными путями. Лучше использовать локальный сервер.

7. Расширение на весь сайт

После успешной обработки engoo нужно применить ту же операцию ко всему репозиторию ai\:

1Перейти в корень

cd C:\Users\user1\Documents\GitHub\ai

2Скопировать скрипт

copy engoo\replace_links.py .

3Изменить BASE_URL

Открыть скрипт в Блокноте:

notepad replace_links.py

Заменить строку:

BASE_URL = "https://item1000-collab.github.io/ai/engoo"

на:

BASE_URL = "https://item1000-collab.github.io/ai"

Это позволит заменить ссылки не только на engoo, но и на trips, dvp, gdc, nc, zen и корневой index.

4Бэкап

cd ..
xcopy ai ai_backup /E /I
cd ai

5Запуск

python replace_links.py

6Проверка

findstr /s /i /c:"item1000-collab.github.io" *.html index

9. Возможные проблемы

«python не является внутренней командой»

PATH не настроен. Переустановить Python, либо вручную добавить в PATH папку:

C:\Users\user1\AppData\Local\Python\bin

Через Параметры → Система → О системе → Дополнительные параметры системы → Переменные среды → Path.

Файл сохранился как .py.txt

При сохранении в Блокноте выбрать «Тип файла: Все файлы (*.*)», либо переименовать:

ren replace_links.py.txt replace_links.py

«can't open file 'replace_links.py': No such file or directory»

Python не находит файл. Проверить:

dir *.py*

Убедиться, что находитесь в правильной папке и файл имеет расширение .py.

Скрипт обработал 0 файлов

Файлы HTML называются index без расширения. Убедиться, что в скрипте есть строка:

for p in ROOT.rglob("index"):

Русский текст превратился в кракозябры

Файлы были в кодировке, отличной от UTF-8 (например Windows-1251). Скрипт читает с errors="ignore", что может терять символы. Решение:

  1. Откатить файлы из бэкапа.
  2. В скрипте заменить кодировку на cp1251: 
    text = path.read_text(encoding="cp1251")
  3. Запустить снова.

Ссылки на другой раздел (/ai/trips/…) не заменились

В BASE_URL указан только /ai/engoo. Для замены по всему сайту использовать BASE_URL = "https://item1000-collab.github.io/ai".

Руководство создано по реальному опыту замены ссылок на сайте item1000-collab.github.io/ai.
