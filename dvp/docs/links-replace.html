1. The task 1. Задача

The site is deployed on GitHub Pages at: Сайт развёрнут на GitHub Pages по адресу: 

https://item1000-collab.github.io/ai/engoo/

Inside the HTML files, all internal links were absolute — for example: Внутри HTML-файлов все внутренние ссылки были абсолютными — например: 

<a href="https://item1000-collab.github.io/ai/engoo/20260901-phantom-opera/index.html">Class material</a>

This causes problems: Это создаёт проблемы:

  • local viewing (via file://) does not work;
  • не работает локальный просмотр (через file://);
  • when the domain changes (migration, mirror, local server), all links break;
  • при смене домена (переезд, зеркало, локальный сервер) все ссылки ломаются;
  • an offline copy of the site does not work.
  • не работает офлайн-копия сайта.

The goal is to replace all absolute links of the form https://item1000-collab.github.io/ai/engoo/… with relative ones: Цель — заменить все абсолютные ссылки вида https://item1000-collab.github.io/ai/engoo/… на относительные: 

./20260901-phantom-opera/index.html      (from the root)
../index.html                             (from a subfolder)

4. Creating the replacement script 4. Создание скрипта замены

1Open NotepadОткрыть Блокнот

The easiest way is from the command line, while in the engoo folder: Проще всего — из командной строки, находясь в папке engoo: 

notepad replace_links.py

2Paste the codeВставить код

import re
from pathlib import Path

# ==== SETTINGS — change to your needs ====
BASE_URL = "https://item1000-collab.github.io/ai/engoo"
# =========================================

ROOT = Path(".").resolve()
pattern = re.compile(re.escape(BASE_URL) + r"(/[^\s\"'<>)]*)?")

count = 0

# Look for *.html, *.htm and extensionless files named "index"
candidates = set()
for mask in ("*.html", "*.htm"):
    candidates.update(ROOT.rglob(mask))
for p in ROOT.rglob("index"):
    if p.is_file():
        candidates.add(p)

for path in sorted(candidates):
    rel_dir = path.parent.relative_to(ROOT)
    depth = len(rel_dir.parts)
    prefix = "../" * depth if depth else "./"

    text = path.read_text(encoding="utf-8", errors="ignore")

    def repl(m):
        tail = m.group(1) or "/"
        return prefix + tail.lstrip("/")

    new = pattern.sub(repl, text)
    if new != text:
        path.write_text(new, encoding="utf-8")
        print("updated:", path)
        count += 1

print(f"\nDone. Files processed: {count}")

3SaveСохранить

The file must be in the engoo folder and have the .py extension. If Windows saved it as replace_links.py.txt — rename it: Файл должен лежать в папке engoo и иметь расширение .py. Если Windows сохранил его как replace_links.py.txt — переименовать:

6. Verifying the result 6. Проверка результата

Searching for leftoversПоиск остатков

findstr /s /i /c:"item1000-collab.github.io" *.html index

If anything is found, there are links the script did not process. Possible reasons: Если найдено — значит есть ссылки, которые скрипт не обработал. Возможные причины:

  • Links to another path — for example /ai/trips/… instead of /ai/engoo/…. The script is configured only for engoo.
  • Ссылки на другой путь — например /ai/trips/… вместо /ai/engoo/…. Скрипт настроен только на engoo.
  • Links in comments <!-- … --> — they do not affect the site but appear in the text.
  • Ссылки в комментариях <!-- … --> — не влияют на работу, но встречаются в тексте.

Local checkЛокальная проверка

Start a simple web server: Запустить простой веб-сервер: 

python -m http.server 8000

Open http://localhost:8000/ and click through the links. Открыть http://localhost:8000/ и походить по ссылкам.

Note: file:// may not work correctly with relative paths. It is better to use a local server. Внимание: file:// может некорректно работать с относительными путями. Лучше использовать локальный сервер.

9. Troubleshooting 9. Возможные проблемы

"python is not recognized as an internal command" «python не является внутренней командой»

PATH is not configured. Reinstall Python, or manually add the folder to PATH: PATH не настроен. Переустановить Python, либо вручную добавить в PATH папку: 

C:\Users\user1\AppData\Local\Python\bin

via Settings → System → About → Advanced system settings → Environment Variables → Path. Через Параметры → Система → О системе → Дополнительные параметры системы → Переменные среды → Path.

The file was saved as .py.txt Файл сохранился как .py.txt

When saving in Notepad, choose "File type: All files (*.*)", or rename it: При сохранении в Блокноте выбрать «Тип файла: Все файлы (*.*)», либо переименовать: 

ren replace_links.py.txt replace_links.py

"can't open file 'replace_links.py': No such file or directory" «can't open file 'replace_links.py': No such file or directory»

Python cannot find the file. Check: Python не находит файл. Проверить: 

dir *.py*

Make sure you are in the right folder and the file has the .py extension. Убедиться, что находитесь в правильной папке и файл имеет расширение .py.

The script processed 0 files Скрипт обработал 0 файлов

HTML files are named index without an extension. Make sure the script contains the line: Файлы HTML называются index без расширения. Убедиться, что в скрипте есть строка: 

for p in ROOT.rglob("index"):

Russian text turned into garbled characters Русский текст превратился в кракозябры

The files were in a non-UTF-8 encoding (e.g. Windows-1251). The script reads with errors="ignore", which may lose characters. Solution: Файлы были в кодировке, отличной от UTF-8 (например Windows-1251). Скрипт читает с errors="ignore", что может терять символы. Решение:

  1. Restore the files from backup.
  2. Откатить файлы из бэкапа.
  3. In the script, change the encoding to cp1251: 
    text = path.read_text(encoding="cp1251")
  4. В скрипте заменить кодировку на cp1251: 
    text = path.read_text(encoding="cp1251")
  5. Run again.
  6. Запустить снова.

Links to another section (/ai/trips/…) were not replaced Ссылки на другой раздел (/ai/trips/…) не заменились

BASE_URL only contains /ai/engoo. To replace across the whole site, use BASE_URL = "https://item1000-collab.github.io/ai". В BASE_URL указан только /ai/engoo. Для замены по всему сайту использовать BASE_URL = "https://item1000-collab.github.io/ai".
