Руководство по настройке VoiceMeeter и сторонних приложений

VoiceMeeter — это мощный виртуальный аудиомикшер для Windows, который позволяет гибко управлять входящими и исходящими аудиопотоками. В этой статье мы рассмотрим правильную настройку самой программы, звуковых параметров Windows, а также конфигурацию Discord, Teams, Lync и популярных браузеров.

1. Настройка самой программы VoiceMeeter

Для корректного распределения звука в интерфейсе VoiceMeeter (например, VoiceMeeter Banana):

  • В блоке Hardware Input 1 выберите ваш физический микрофон (например, Микрофон (2- USB Audio Device)).
  • Для отправки звука с микрофона в программы связи убедитесь, что включена шина B1 (а B2 можно отключить при отсутствии необходимости в дополнительном виртуальном канале).
  • В правой части (Hardware Out) в устройстве A1 укажите ваши основные динамики или наушники.

2. Системные настройки звука Windows

Устройства воспроизведения (Playback)

В параметрах звука Windows во вкладке «Воспроизведение» установите устройством по умолчанию VoiceMeeter Input (VB-Audio VoiceMeeter VAIO). В этом случае весь системный звук будет отправляться в микшер.

Устройства записи (Recording)

Во вкладке «Запись» выберите устройством по умолчанию VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO). Это позволит использовать обработанный сигнал микрофона во всех приложениях.

3. Настройка программ связи

Discord

Перейдите в Настройки пользователя → Голос и видео:

  • Устройство ввода (Microphone): VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Устройство вывода (Speaker): VoiceMeeter AUX Input (VB-Audio VoiceMeeter VAIO) (для отдельного управления звуком голосового чата)

Microsoft Teams

В меню настроек устройств выберите:

  • Динамики (Speaker): VoiceMeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Микрофон (Microphone): VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO)

Microsoft Lync / Skype for Business

В окне параметров в разделе «Звуковое устройство» установите:

  • Динамик: VoiceMeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Микрофон: VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Звонок: VoiceMeeter AUX Input (VB-Audio VoiceMeeter VAIO)

4. Настройка браузеров

Mozilla Firefox (и веб-сервисы)

При использовании голосовых сервисов в браузере (например, веб-приложений с передачей речи) выбирайте соответствующий виртуальный выход/канал B1 / B2 в разрешениях страницы или настройках веб-приложения.

Яндекс Браузер / Chromium-браузеры

В настройках браузера (Настройки → Сайты → Расширенные настройки сайтов → Доступ к микрофону) установите микрофоном по умолчанию VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO) (System default).

Совет: Всегда проверяйте, чтобы частота дискретизации в настройках Windows (например, 48000 Hz) совпадала с частотой, установленной в настройках VoiceMeeter, во избежание треска и задержек звука.
