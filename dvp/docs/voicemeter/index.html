VoiceMeeter Banana Setup Guide Инструкция по настройке VoiceMeeter Banana

This guide will help you properly configure audio routing in the VoiceMeeter Banana virtual mixer, Windows OS, messaging apps, and web browsers. Данное руководство поможет вам правильно настроить маршрутизацию звука в виртуальном микшере VoiceMeeter Banana, операционной системе Windows, мессенджерах и браузерах.

Step 1. VoiceMeeter Banana Configuration Шаг 1. Настройка VoiceMeeter Banana

Set the main mixer parameters for proper microphone, playback, and virtual bus operation: Для корректной работы микрофона, воспроизведения звука и виртуальных шин выставьте основные параметры микшера:

  • Hardware Input 1: Select your physical microphone (e.g., Microphone (2- USB Audio Dev)). Hardware Input 1: выберите ваш физический микрофон (например, Микрофон (2- USB Audio Dev)).
  • A1 / A2 (Hardware Out): Select your physical speakers or headphones in the top right corner. A1 / A2 (Hardware Out): выберите ваши физические динамики или наушники в правом верхнем углу.
  • B1 and B2 Buses: Used to route virtual audio to applications and browsers. Шины B1 и B2: используются для передачи виртуального звука в программы и браузеры.

Step 2. Windows Sound Settings Шаг 2. Настройка системных звуков Windows

Open the classic Windows sound control panel (Control Panel -> Sound): Перейдите в классическую панель управления звуком Windows (Control Panel -> Sound):

Playback Tab Вкладка «Воспроизведение» (Playback)

Set VoiceMeeter Input (VB-Audio VoiceMeeter VAIO) as the Default Device. Установите устройство VoiceMeeter Input (VB-Audio VoiceMeeter VAIO) в качестве устройства по умолчанию (Default Device).

Recording Tab Вкладка «Запись» (Recording)

Set VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO) as the default microphone (Default Device). Установите устройство VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO) в качестве микрофона по умолчанию (Default Device).

Step 3. Messengers and Communication Software Шаг 3. Настройка мессенджеров и программ для звонков

Discord

  • Microphone (Input Device): Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO) Microphone (Устройство ввода): Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Speaker (Output Device): Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO) Speaker (Устройство вывода): Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)

Microsoft Teams

  • Speaker: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Microphone: Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)

Lync / Skype for Business

  • Speaker: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO) Динамик: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Microphone: Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO) Микрофон: Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Ringer: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO) Звонок: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)

Step 4. Web Browsers and Online Services Шаг 4. Настройка браузеров и веб-сервисов

1. Yandex Browser / Chromium Browsers (Default Option) 1. Яндекс Браузер / Chromium-браузеры (Основной вариант по умолчанию)

By default, Yandex Browser (or other Chromium-based browsers) is used for web services and calls with channel B1. По умолчанию для браузерных веб-сервисов и звонков используется Яндекс Браузер (или другие браузеры на базе Chromium) с каналом B1.

In microphone permissions, select Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO). В настройках прав и разрешений микрофона выберите Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO).

2. Mozilla Firefox (Additional Option for Linking 2 Chats) 2. Mozilla Firefox (Дополнительный вариант для связи 2-х чатов)

Note: Mozilla Firefox is used as a secondary browser. If you need to link two separate voice chats or web services simultaneously in different browsers, use Firefox with bus B2. Обратите внимание: Mozilla Firefox используется в качестве дополнительного браузера. Если вам необходимо одновременно связать два разных голосовых чата или веб-сервиса в разных браузерах, используйте Firefox с шиной B2.

In the address bar or website microphone permissions, select virtual channel B2. В адресной строке или настройках доступа к микрофону сайта выбирайте виртуальный канал B2.
