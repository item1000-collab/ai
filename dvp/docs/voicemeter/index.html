Полная инструкция по настройке VoiceMeeter Banana и софта

Данное руководство поможет вам правильно настроить маршрутизацию звука в виртуальном микшере VoiceMeeter Banana, операционной системе Windows, мессенджерах и браузерах.

Шаг 1. Настройка VoiceMeeter Banana

Для корректной работы микрофона, воспроизведения звука и виртуальных шин выставьте основные параметры микшера:

  • Hardware Input 1: выберите ваш физический микрофон (например, Микрофон (2- USB Audio Dev)).
  • A1 / A2 (Hardware Out): выберите ваши физические динамики или наушники в правом верхнем углу.
  • Шины B1 и B2: используются для передачи виртуального звука в программы и браузеры.

Шаг 2. Настройка системных звуков Windows

Перейдите в классическую панель управления звуком Windows (Control Panel -> Sound):

Вкладка «Воспроизведение» (Playback)

Установите устройство VoiceMeeter Input (VB-Audio VoiceMeeter VAIO) в качестве устройства по умолчанию (Default Device).

Вкладка «Запись» (Recording)

Установите устройство VoiceMeeter Out B1 (VB-Audio VoiceMeeter VAIO) в качестве микрофона по умолчанию (Default Device).

Шаг 3. Настройка мессенджеров и программ для звонков

Discord

  • Microphone (Устройство ввода): Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Speaker (Устройство вывода): Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)

Microsoft Teams

  • Speaker: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Microphone: Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)

Lync / Skype for Business

  • Динамик: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)
  • Микрофон: Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO)
  • Звонок: Voicemeeter AUX Input (VB-Audio VoiceMeeter VAIO)

Шаг 4. Настройка браузеров и веб-сервисов

1. Яндекс Браузер / Chromium-браузеры (Основной вариант по умолчанию)

По умолчанию для браузерных веб-сервисов и звонков используется Яндекс Браузер (или другие браузеры на базе Chromium).

В настройках прав и разрешений микрофона выберите Voicemeeter Out B1 (VB-Audio VoiceMeeter VAIO).

2. Mozilla Firefox (Дополнительный вариант для связи 2-х чатов)

Обратите внимание: Mozilla Firefox используется в качестве дополнительного браузера. Если вам необходимо одновременно связать два разных голосовых чата или веб-сервиса в разных браузерах, используйте Firefox с шиной B2.

В адресной строке или настройках доступа к микрофону сайта выбирайте виртуальный канал B2.
